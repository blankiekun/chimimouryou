# Server side

Everything that runs next to the static app: the nginx configuration, the
catalog builder and the Python services. With Docker (the usual way) they run
from `docker-compose.yml`, see [docs/INSTALL.md](../docs/INSTALL.md); every
setting is in [docs/CONFIGURATION.md](../docs/CONFIGURATION.md).

| Path                                                  | What it is                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                            |
| ----------------------------------------------------- | --------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| `nginx-ebook-reader.conf.template`, `render-nginx.sh` | The site: app, Calibre files, the v1 API, access checks (`auth_request`). `render-nginx.sh` fills in paths and service addresses when the web container starts.                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                       |
| `build-catalog.py`                                    | Builds the catalog from a copy of Calibre's `metadata.db` into `library.db`'s books and `catalog.json` (no longer served; read by `jiten`, `mokuro` and `import`): best format per book, manga archives, tags, rating, publisher, series (Calibre's or inferred from volume numbers), unique titles that stay put, and `cover.jpg` extracted from EPUBs without a Calibre cover. Runs as the library owner.                                                                                                                                                                                                                                                           |
| `account/`                                            | Accounts, sessions, admins and permissions, and the `auth_request` answers for every protected location (Python standard library; security notes at the top of `service.py`). `ebook-account` is its command line.                                                                                                                                                                                                                                                                                                                                                                                                                                                    |
| `api/`                                                | The v1 API (`/api/v1/`, port 8769): catalog delta, search, and reading data (progress, statistics, goals, highlights, per-book and account docs, game records and their progress, statistics and saves, series and metadata overrides) in `state/api/library.db` (`apidb.py`: schema and the newer-`modified`-wins rule). `migrate.py` copies the old WebDAV sync folders into it (dry run unless `--apply`; `deploy.sh` and `ebook-update` run it, the first time with `web` stopped). The app's only storage API.                                                                                                                                                   |
| `import/`                                             | Queue that adds uploaded books to Calibre with `calibredb add`, one at a time, then rebuilds the catalog. The only writer of `metadata.db`.                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                           |
| `jiten/`                                              | The difficulty service (`service.py`); the engine it runs lives in [`engine/`](../engine/) and is copied beside it in the image: `core.py` (V98 and its 1-10 scale, `core-scale.json`) and word lists with [Jiten](https://github.com/Sirush/Jiten)'s word grouping (Apache-2.0, see `engine/LICENSE`): `deconjugator.json` is Jiten's; `features.py` and `deconjugator.py` port its parser to Python with Sudachi. Jiten's frequency list is bundled (`engine/data/`, CC BY-SA 4.0) and installed as `frequency-dictionary.zip` in its state folder on start when none is there. Runs only when started (admin panel → Tools, or for books selected in the library). |
| `assign-series.py`                                    | Writes inferred series into Calibre itself (dry run unless `--apply`; run with `calibre-debug -e`, command in the docstring).                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                         |
| `tests/`                                              | `python3 -m unittest discover -s engine/tests && python3 -m unittest discover -s server/tests` from the repository root (standard library only).                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                      |

The AI features (Ask AI, Story so far, Lorebook, AI voice) call OpenRouter and
ElevenLabs directly from the browser, with keys each reader enters in
Settings → AI; nothing on the server is involved.

## Who may do what

nginx asks the account service before serving anything but the app itself:

- **Read** the library and catalog: an account, a trusted network
  (`TRUSTED_NETWORKS`), or anyone with `PUBLIC_READS=1`.
- **Write** reading data (`/api/v1/`): an account, or a signed-out reader
  from a trusted network (whose rows are the shared account `''`'s). Text
  copies (`/api/v1/books/{id}/text`, the source of everyone's generated
  furigana) need an account.
- **Add books to Calibre, change series for everyone, start difficulty jobs**:
  admins, or accounts with the `import`, `series` or `difficulty` permission
  (Settings → Account → User permissions, or `ebook-account permissions NAME …`).
  Series, book details and covers (`/api/v1/series|metadata/`) need `series`.
- **Own reading data** (the account's rows in `library.db`, game records): only
  that account.

Signing in needs HTTPS unless `ALLOW_HTTP_ACCOUNTS=1`. There is no sign-up:
admins add accounts in Settings → Account, or with
`ebook-account add NAME [--admin]` (asks for a password of at least 8
characters); create the first admin on the server.
